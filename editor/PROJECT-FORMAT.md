# KWZ Studio 工程格式 v1

扩展名：`.kwzproj`。容器：标准 ZIP，Deflate 压缩。工程是独立文件，不依赖源 KWZ 的路径。
它用于保留可编辑对象；游戏仍使用单独导出的、带有效签名的 `.kwz` 文件。

## 区段

| ZIP 项目 | 内容 |
| --- | --- |
| `base.kwz` | 尚未合成对象的完整动画底图、图层、帧元数据、缩略图和音轨。保持 libkwz 可读的 KWZ 结构；编辑过程中其旧签名可能失效，导出时重新签名。 |
| `project.json` | UTF-8 JSON：格式标识、版本、当前帧和有序对象列表。 |

`project.json` 的顶层属性：

| 字段 | 类型 / 含义 |
| --- | --- |
| `Format` | 固定字符串 `KWZStudioProject` |
| `Version` | 整数 `1`，遇到未知版本拒绝打开 |
| `CurrentFrame` | 从 0 开始的当前帧位置 |
| `Objects` | 按同层绘制顺序排列的对象数组，后面的对象覆盖前面的对象 |

## 对象

| 字段 | 含义 |
| --- | --- |
| `Id` | 唯一 GUID，复制对象或复制包含对象的帧时生成新 ID |
| `Frame`, `Layer` | 从 0 开始的所属帧与图层，图层范围 0–2 |
| `Kind` | `0` 文字、`1` 矩形、`2` 椭圆 |
| `X`, `Y`, `Width`, `Height` | 原始 320×240 画布中的整数坐标与尺寸，允许部分位于画布外 |
| `Ink` | `0` 透明、`1` 第一墨色、`2` 第二墨色；实际颜色取所属帧图层的调色板 |
| `Text`, `FontSize`, `FontFamily` | 文字内容、像素字号、系统字体族名；字体文件不内嵌 |
| `Filled`, `StrokeWidth` | 形状是否实心、轮廓线宽 |

文字的宽高由字体和内容测量得到，拖动缩放会调整字号。形状宽高可独立调整。
对象只作用于所属帧；帧移动、删除、复制时同步更新对象归属。

## 读写与导出

加载工程先检查版本、区段大小、底图 CRC 和对象字段，再替换当前文档；加载失败保留原编辑状态。
读取 ZIP 直接在内存中完成，不向磁盘解包。对象坐标、数量和解压长度设有上限。
保存先写一个同目录临时文件并刷新到磁盘，成功后替换目标；失败时清理临时文件。

导出在底图的独立副本上按帧、按图层合成对象，重建受影响帧的压缩数据，更新缩略图、
CRC 和 RSA 签名。此操作不改变当前工程的对象、底图、路径或未保存状态。
撤销历史保存在内存中，不写入工程；重新打开后仍可继续编辑所有保留的对象。
